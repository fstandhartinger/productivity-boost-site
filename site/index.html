What I’m building now.

01 — Decision Modelsdecisionmodels.io

One API, many open decision models.

Decision models don’t write text. They read a situation and a set of options and return one answer per option with a probability, in a single forward pass. That makes them fast and cheap enough to sit in the middle of any workflow. Decision Models hosts strong open ones behind one API that speaks the same request format as Jev, TypeSafe AI’s decision model.2 (note)

decisionmodels.io (opens in a new tab)↗Quickstart (opens in a new tab)↗Models (opens in a new tab)↗

Models
s1-fast · s1-pro · s1-vision (image + text) · quyet-1-large
Interfaces
REST API, hosted MCP server, Jev-compatible requests
EU tier
Processed only in the EU, payloads not stored, never used for training

02 — REAXreax.co · Bittensor subnet 92

An open network that serves decision models.

On REAX, anyone with a capable GPU can host the models, validators check every answer, and the network rewards correct, fast serving. It runs as subnet 92 on Bittensor and has been live on mainnet since 14 October 2026. Decision Models is the customer-facing product on top.

reax.co (opens in a new tab)↗Mine with your GPU (opens in a new tab)↗REAX Engine on GitHub (opens in a new tab)↗

Miner pools
Four: s1-fast and s1-pro (the API models) on NVIDIA GPUs, plus s1-lite for small GPUs incl. Jetson Orin and s1-cpu for plain CPUs
Competitions
An engine track for the fastest correct serving and a generalist decision-model track, both open since October 2026
Onboarding
Give your coding agent one link; it practises on a local chain with test TAO first, and you approve every payment
