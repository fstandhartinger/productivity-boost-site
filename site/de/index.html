01 — Produkte

Woran ich gerade baue.

Decision Modelsdecisionmodels.io

Eine API, viele offene Entscheidungs­modelle.

Entscheidungsmodelle schreiben keinen Text. Sie lesen eine Situation und die Optionen und liefern pro Option eine Antwort mit Wahrscheinlichkeit, in einem einzigen Durchlauf. Damit sind sie schnell und günstig genug, um mitten in jedem Workflow zu arbeiten. Decision Models stellt starke offene Modelle hinter einer API bereit, die dasselbe Anfrageformat spricht wie Jev, das Entscheidungsmodell von TypeSafe AI.2 (Anmerkung)

decisionmodels.io (öffnet in neuem Tab)↗Quickstart (öffnet in neuem Tab)↗Modelle (öffnet in neuem Tab)↗

Modelle
s1-fast · s1-pro · s1-vision (Bild + Text) · quyet-1-large
Schnittstellen
REST-API, gehosteter MCP-Server, Jev-kompatible Anfragen
EU-Option
Verarbeitung nur in der EU, keine Speicherung der Inhalte, nie für Training genutzt

REAXreax.co · Bittensor-Subnet 92

Ein offenes Netzwerk, das Entscheidungs­modelle bereitstellt.

Bei REAX kann jede und jeder mit einer passenden GPU die Modelle betreiben, Validatoren prüfen jede Antwort, und das Netz belohnt richtige, schnelle Auslieferung. REAX läuft als Subnet 92 auf Bittensor und ist seit dem 14. Oktober 2026 im Mainnet live. Decision Models ist das Kundenprodukt, das darauf aufsetzt.

reax.co (öffnet in neuem Tab)↗Mit eigener GPU minen (öffnet in neuem Tab)↗REAX Engine auf GitHub (öffnet in neuem Tab)↗

Miner-Pools
Vier: s1-fast und s1-pro (die API-Modelle) auf NVIDIA-GPUs, dazu s1-lite für kleine GPUs inkl. Jetson Orin und s1-cpu für normale CPUs
Wettbewerbe
Ein Engine-Track für die schnellste korrekte Auslieferung und ein Generalist-Track für Entscheidungsmodelle, beide seit Oktober 2026 offen
Einstieg
Dem Coding-Agenten einen Link geben; er übt erst auf einer lokalen Chain mit Test-TAO, und jede Zahlung geben Sie selbst frei
